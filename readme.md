# Important Books, Papers, and Multimedia on the Development of the Web

This repo contains a master list of important books, papers, and multimedia about computer technology. The main focus is on the development of programming and the modern World Wide Web. Included are some materials about adjacent topics, such as the development of artificial intelligence and relational databases.

The docs will be eventually arranged along a vertical tinmeline, with individual information on each document organized as if on a card from a card acatalog in an old library. I hope to have the cards written as modular elements that have a slight animation when you click on them.
